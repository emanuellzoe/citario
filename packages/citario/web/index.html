Pay-per-citation for AI agents · NEAR

Agents pay authors per citation. The text never goes on chain.

A model running in a TEE on NEAR AI Cloud reads the article and the agent's question together, picks the smallest passage that answers it and prices it inside the author's bounds. A NEAR contract enforces the bounds, pays the author, and the passage unlocks only after payment.

How it works

Five steps, two signatures, one contract.

The model proposes; code clamps; the chain enforces. Nobody downstream has to trust the facilitator's word.

01

Register

The author registers the article's sha256, a floor and a ceiling. The text stays encrypted off chain.

author
02

Quote in a TEE

The agent states a need. A NEAR AI Cloud model picks the passage and a price; the response is signed inside the enclave.

NEAR AI Cloud
03

Clamp & sign

Code strips injected instructions, caps the span at 25% and clamps the price to the bounds, then signs the quote.

facilitator
04

Pay on chain

The agent calls cite with a key that can do nothing else. The contract checks signature, bounds, expiry and single use.

citario contract
05

Deliver & verify

The passage unlocks after the tx is final. The receipt can be checked by anyone against the chain.

anyone

Run it

Ask, price, pay, unlock.

A live run against testnet. The quote comes from the TEE; payment is a real cite transaction from the reader agent's limited key.

“Pay & unlock” uses the agent's function-call key from .env and only works on localhost. In production the agent pays itself with pnpm run reader.
